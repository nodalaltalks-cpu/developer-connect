## Where to list (free, in order of value)

1. **Bing Places** (https://www.bingplaces.com): can import from a verified Google Business Profile, so do it right after verification.
2. **Justdial** and **Sulekha**: free India listings. Use the wording above. Check whether the website link is shown; do not expect search value from every directory.
3. **LinkedIn company page** (links back; the founder page already exists).
4. **UAE listings** for the Dubai side (Yellow Pages UAE and similar), once a Dubai profile is set up.
5. Skip bulk directory submission tools and link packs. A handful of relevant listings beat hundreds of low-quality ones.

## Answers that earn real links (Quora, Reddit, NRI forums)

Rule: answer the question fully first, link a guide only if it is the best source, and say it is your site. One reply per thread, never the same text twice.

Good fits and the page to cite:
- "How to buy a flat in Mumbai step by step": /guides/how-to-buy-a-flat-in-mumbai
- "Hidden costs when buying property in Mumbai": /guides/hidden-costs-of-buying-property-in-mumbai
- "Mumbai vs Navi Mumbai vs Thane": /guides/mumbai-vs-navi-mumbai-vs-thane
- "Buying a flat in Mumbai as an NRI" and Dubai buyer questions: the matching guide or /buy-direct-from-developer/dubai
- "Is this developer RERA registered?": /developers/{slug} plus the MahaRERA search

Disclosure line to end with: "I run Developer Connects, which wrote the guide linked above."

## Not done on purpose

- No accounts were created and nothing was posted on anyone's behalf. Account creation and sign-in are yours.
- No paid links, link exchanges, comment spam or auto-posting. They can get the site demoted.
- No claims such as "best", "top" or "verified" in any text, matching the site's copy rules.
